## Design Direction

The visual language combines:

- Editorial typography using **Newsreader**, **Archivo**, and **DM Mono**
- Paper-and-ink neutral tones with acid-green technical highlights
- Red annotation accents for navigation and section indexing
- Ruled grids and information-dense layouts inspired by engineering documentation
- A custom control/telemetry diagram in the hero section
- Large typographic compositions instead of conventional portfolio cards
- Responsive layouts for desktop and mobile
- Accessible keyboard focus states and reduced-motion support

## Run Locally

No build tool or package installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/rakibai-dev/portfolio-editorial.git
   ```

2. Open `index.html` in a modern browser.

For local development, you can also serve the folder with any static HTTP server.

## Deployment

The project is a static HTML/CSS/JavaScript site and can be deployed directly with **GitHub Pages** or any static hosting provider.
